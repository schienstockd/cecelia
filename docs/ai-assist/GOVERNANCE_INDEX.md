# Governance index — process docs, one grep point

**What this is.** A single-page index of the docs that govern *how* the codebase is developed, reviewed, and measured — not the docs that describe *what* the code does. Sits alongside [`INVENTORY.md`](../../INVENTORY.md) (which indexes code components) so that a fresh session has one place to look for process rules before writing anything new about them.

**Ownership.** Accepted-to-drift-slowly. Not a person, not a CI gate. The [`.claude/hooks/check_commit_recital.py`](../../.claude/hooks/check_commit_recital.py) hook may later grep touched paths against the *Doc* column here and warn once at reservations time if a governance doc changed without this index being touched; until that hook lands, staleness is caught only by whoever next audits the layer. (The citation-currency check that was meant to cover it was retired 2026-09-30 — [`../todo/GOVERNANCE_LAYER_AUDIT_PLAN.md`](../todo/GOVERNANCE_LAYER_AUDIT_PLAN.md) Item 4.) Dangling paths in this doc still fail CI (`test_doc_pointer_convention.py`).

**Scope.** Active governance docs only. Frozen archive prompts and audits live under [`../archive/`](../archive/) and are not indexed here (they are frozen by policy — [`../archive/governance_layer_audit.md`](../archive/governance_layer_audit.md) is the most recent audit output, [`../archive/drift_prevention_mechanism_audit.md`](../archive/drift_prevention_mechanism_audit.md) the prior).

## Adding or retiring a doc

- **New governance doc:** add a row here in the same commit. If the new doc doesn't fit an existing column (e.g., it's a decision record without a revisit trigger), state "(none stated)" explicitly.
- **Retiring a doc:** move it to `docs/archive/` with the ARCHIVED banner, remove its row here, and leave a one-line note in the audit doc that ran the retirement.
- **Renaming a doc:** update the row's link. If the doc is cited elsewhere (grep `docs/` + `CLAUDE.md` + `INVENTORY.md` for the old path), fix those citations in the same commit.
