G3 — chunk delivery to the browser, option B

Two delivery designs against the real store, one timepoint, 4 channels. A: the store as it is — one HTTP request per blosc chunk, 1116 of them. B: four requests, one per channel, server assembles and HTTP Content-Encoding does the compression so the browser decodes nothing itself. The yardstick is the measured incumbent: napari pays ~1.2 s per 4-channel timepoint step today, of which only ~6–20% is disk IO.
