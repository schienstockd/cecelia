**Verified** = read in code or seen in a screenshot. **Inference** = labelled where used.

**Classes**
- **MUST** (must interrupt): the warning is shown inline at the action itself (Run, plot, export), so the user meets it without looking for it. This does not mean a modal. QC stays advisory everywhere (`lib/severity.ts`, qc.jl never raises "error").
- **VIS** (should be visible): a status the user sees without opening anything.
- **FINE**: fine where it is.

## Notes

**Must interrupt (3):** #1 stats pseudoreplication, #2 stale outputs after an upstream re-run, #3 missing calibration at Run. All three are already computed. The GUI does not show any of them at the action they invalidate: the plot or export, the re-run, the measuring run. None needs a modal. An inline line at the action is enough, and it keeps QC advisory.

**Pattern.** The checks that work well (#14–#20) sit on the control they qualify. The weak ones are buttons the user has to think of pressing (#5, #9, #13) or tooltips (#7, #8, #11). TaskRunner, the one place every processing step passes through, shows no finding about the selected images except axis gating and the "When to use" lines.

**One visual language? No.** Verified in code:
- Icons: `pi-sliders-h` for Acquisition, which `lib/iconLegend.ts:153` reserves for "Viewer controls, or how a canvas is laid out", so this is a legend violation. `pi-chart-bar` for cohort (legend: "Behaviour and QC plots"), `pi-flag` for QC, `pi-exclamation-triangle` for calibration, `pi-verified` for claims, a tier dot for maturity, `pi-history` for the board record, `pi-bell` for the lab log.
- Three ambers: `.cc-dot-warn` #E69F00 (Acquisition), `--cc-sev-warn` #fab219 (cohort, QC dot, claim count), `--cc-warn` #f59e0b. Cohort also hard-codes `rgba(250,178,25,.1)` (`CohortCheckButton.vue:109`).
- Two "ok" colours: the QC tick uses green `--cc-sev-ok`, while PRIMITIVES says status dots are "sky blue, never green".
- Two button styles: Acquisition uses `cc-btn cc-btn-ghost`. Cohort is a bespoke scoped `.cohort-check-btn`, which is why it paints brighter in every shot.
- Not one surface carries a "check" accent. Plan Decision 4 asks for exactly one.

**Rule of three.** AcqCheckButton, CohortCheckButton and ClaimStrip are the same widget: a check name, an open-problem count with severity, and a click that opens findings with "Next" lines. That is three sites, which is the evidence PRIMITIVES asks for before a new shared `CheckButton` (built on `lib/severity.ts`, `.cc-dot`, and `InlineNote` with `lines`). It is also where the single check accent token lands (P1 colour roles).
